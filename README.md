# 🌴 Goa Guide — Complete GitHub Test Project

Mobile-friendly **HTML + JSON backend** for the Goa Guide project.

### Included sections
Beaches • Places to Visit • Hindu Temples • Churches • Forts • Waterfalls & Wildlife • Museums & Heritage • Where to Stay • Goan Food • Getting Around • Restaurants • Bike & Car Rental • Emergency & Government Help • Tourist Rules • 13 Tourist Scam Alerts • Important Places Near Me • Nightlife • Shopping • Money & Banking.

### Features
- Material 3-inspired light UI
- Mobile-first responsive layout
- Home search
- Section search
- Real Goa names and practical descriptions
- Google Maps search links
- Emergency call buttons
- Wikimedia Commons image links where verified
- Local SVG fallback artwork
- Separate JSON backend files
- Ready for GitHub Pages
- Ready for a future Android app to consume the JSON

### GitHub Pages
Upload the whole folder → GitHub repository → Settings → Pages → Deploy from `main` → `/ (root)`.

Do not open with `file://` if testing JSON loading; use GitHub Pages or a local HTTP server.

### Data source notes
Tourist place names are based primarily on Goa Tourism/GTDC listings. Emergency numbers use current Government of Goa/Goa Police pages. Business, operating hours, prices, ferry schedules and other changing information should be rechecked before production.

### Image policy
Wikimedia Commons files are linked only where a specific file was verified. Check the license on each Commons page before redistribution. The project does not copy Google Maps/Google Images content.
